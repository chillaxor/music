# GD 音乐播放器 v3

核心功能：
- 网易云 / QQ 音乐 / 酷狗 / 酷我 / 咪咕多源搜索
- 多源结果自动去重
- 在线播放、暂停、进度控制
- 专辑封面
- LRC 歌词接口
- 收藏状态本地保存
- 最近播放历史本地保存
- 当前歌曲信息与底部播放器
- 播放队列基础结构

GD Studio 的公开资料显示其 API 提供 search、url、pic、lyric 接口，并支持多个音乐源。接口及第三方音乐内容可能变化，使用前应确认服务条款与内容授权。

注意：本项目不内置或批量打包第三方音乐文件。API 能返回播放 URL 不等于获得了音乐、歌词或封面的再分发授权。若要公开发布 APK，应自行确认相关版权和平台条款。
